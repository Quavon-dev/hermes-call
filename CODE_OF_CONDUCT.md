# Code of conduct

Hermes Call adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. It applies to everyone taking part in this project: in issues, pull
requests, discussions, reviews, and when representing the project elsewhere.

In short: be respectful and constructive, assume good intent, accept feedback gracefully, and
focus on what is best for the people using Hermes Call. Harassment, insults, personal or political
attacks, sexualized language or imagery, publishing someone's private information, and other
conduct that would be inappropriate in a professional setting are not accepted.

## Reporting

Report behaviour that violates this code privately to the maintainers through the same channel as
security reports: GitHub's
[private reporting](https://github.com/quavon-dev/hermes-call/security/advisories/new) (see
[SECURITY.md](SECURITY.md)); start the title with "Code of conduct". Reports are read only by the
maintainers and handled confidentially. Please do not report conduct issues in public threads.

## Enforcement

The maintainers of Quavon UG (haftungsbeschränkt) decide on and enforce this code, following the
Contributor Covenant's enforcement guidelines: from a private warning, through a temporary ban from
interacting with the project, up to a permanent ban for repeated or severe violations. Maintainers
who do not follow it in good faith may face the same consequences.
